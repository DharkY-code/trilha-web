Nível 1 · HTML

Desafio 1 — Página de apresentação

Crie uma página HTML com título, um parágrafo de apresentação, uma lista de três objetivos e um link para uma fonte de estudo.

Critérios:
  • Documento HTML válido com lang="pt-BR".
  • Título dentro de head e conteúdo dentro de body.
  • Uso de h1, p, ul, li e a de forma semântica.
Ver dica

Comece com <!doctype html>, use <html lang="pt-BR"> e não pule diretamente para CSS.

Nível 2 · CSS

Desafio 2 — Cartão responsivo

Transforme a página anterior em um cartão centralizado, legível em celular e computador.

Critérios:
  • Layout sem largura fixa que quebre em telas pequenas.
  • Espaçamento consistente, contraste e foco visível.
  • Teste em pelo menos duas larguras de tela.
Ver dica

Experimente max-width, margin-inline: auto, padding e uma media query simples.

Nível 6 · SQL

Desafio 3 — Consultas de uma biblioteca

Imagine uma tabela livros(id, titulo, autor, ano, disponivel). Escreva uma consulta que liste os livros disponíveis publicados depois de 2020, do mais recente ao mais antigo.

Ver solução depois de tentar
SELECT id, titulo, autor, ano
FROM livros
WHERE disponivel = TRUE AND ano > 2020
ORDER BY ano DESC;
